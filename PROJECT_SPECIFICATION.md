# Project Specification — LaporKetua

## Wilayah
RW 06, Kelurahan Jembatan Besi, Kecamatan Tambora, Jakarta Barat, DKI Jakarta.
RT: 01, 02, 03, 04, 05, 06, 07, 08, 09, 11, 12, 13, 14.

## Titik referensi peta
- SDN Jembatan Besi: -6.153027, 106.798433.
- Sekretariat Pos RW 06: -6.153560, 106.798694.

Titik di atas hanya untuk tampilan awal dan marker peta. Tidak merepresentasikan batas wilayah atau pusat resmi RW.

## Role
- Warga: registrasi, membuat dan melacak laporan, notifikasi.
- Admin RW: statistik, daftar laporan/warga, verifikasi dan perubahan status, peta.
- Petugas lapangan: melihat pekerjaan yang perlu ditindaklanjuti (assignment workflow belum selesai).

## Status laporan
Menunggu Verifikasi, Diverifikasi, Sedang Diproses, Selesai, Ditolak.

## Kategori
Jalan Rusak, Sampah Menumpuk, Lampu Jalan Mati, Saluran Air Tersumbat, Pohon Tumbang, Fasilitas Umum Rusak, Keamanan Lingkungan, Lainnya.

## Keputusan platform
Flask, Jinja2, Bootstrap 5, PostgreSQL target, SQLite lokal, Leaflet, OpenStreetMap, Chart.js (dashboard chart lanjutan), Scikit-learn, PWA.
